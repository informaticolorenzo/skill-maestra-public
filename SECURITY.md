# Política de seguridad

## Versiones con soporte

Solo la rama `main`. No hay versiones anteriores mantenidas.

## Cómo avisar de un problema

Si encuentras algo que pueda comprometer a quien use este proyecto (un script que haga algo inesperado, datos sensibles que se hayan colado, una dependencia con vulnerabilidad), **no abras un issue público**. Usa la opción "Report a vulnerability" de la pestaña *Security* de este repositorio, que crea un aviso privado.

Describe qué has encontrado, cómo reproducirlo y qué impacto crees que tiene. Intentaré responder en una semana y, si se confirma, publicar la corrección y mencionarte en el aviso si así lo quieres.

## Alcance

Este proyecto es HTML estático, scripts de PowerShell que se ejecutan en tu máquina y archivos de texto para agentes de IA. No tiene servidor ni recoge datos. Revisa siempre lo que ejecutas, como con cualquier script descargado.
